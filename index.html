Tentang aplikasi

CraftKit mengumpulkan alat yang biasa dibutuhkan pemain dan admin server Minecraft dalam satu aplikasi. Edit file dunia, atur server, buat skin, sampai hitung XP, semuanya di HP tanpa perlu komputer.

Editor NBTBuka level.dat, playerdata, dan file .nbt. Java dan Bedrock terbaca otomatis.
server.propertiesUbah pengaturan server lewat tombol dan kolom, atau buat dari template.
Editor SkinGambar di model 3D atau peta 2D, lengkap dengan cermin, balik, dan warna.
Skin PackKumpulkan banyak skin dan ekspor jadi add-on .mcaddon.
Kotak Alat11 alat: UUID, MOTD, koordinat, XP, /give, whitelist, seed, dan lainnya.
